# 拾匠 PWA

拾匠是一个纯净手工教程分享小软件，包含首页推荐、手工分类、传统国风非遗专区、发布作品 AI 预审、匠友问答、我的工坊、收藏和离线安装能力。

## 使用

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build:pwa
```

构建后 `dist/` 可部署到 GitHub Pages、任意静态服务器，或作为 PWA 安装源。云端数据文件位于 `public/cloud/shijiang-data.json`，部署后会通过站点 URL 拉取；网络不可用时自动使用内置兜底数据。

## 主要模块

- 首页：精选教程、活动打卡、教程详情、点赞收藏。
- 分类：通用手工与传统国风分类筛选、合规拦截清单。
- 传统国风：节日专题、非遗分类、材料互换。
- 发布：图片预览、材料/步骤表单、AI 内容预审、本地发布。
- 问答：新增问题、问题状态与回复数展示。
- 我的工坊：作品、收藏、非遗统计和 PWA 安装入口。
